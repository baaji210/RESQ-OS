# RESQ-OS
**RESQ-OS | AI-Assisted Disaster Response & Rescue Coordination**

An intelligent emergency-response platform that centralizes disaster reports, prioritizes incidents using explainable rule-based triage, visualizes affected locations on an interactive map, and recommends rescue resources for human dispatcher approval. Built to improve emergency coordination, situational awareness, and rescue mission tracking, with future scope for drone-assisted search and thermal imaging.
